# 💼 HR Analysis Dashboard (Power BI)

This project is a **Human Resources Analysis Dashboard** built using **Power BI**. It helps visualize key HR metrics such as employee attrition, department-wise distribution, job satisfaction, age demographics, and education background. This dashboard enables HR teams to make data-driven decisions and understand workforce trends.

---

 Dashboard Overview

Key Metrics:
- **Total Employees:** 1470  
- **Attrition Count:** 237  
- **Attrition Rate:** 16.12%  
- **Active Employees:** 1233  
- **Average Employee Age:** 37  

---

 Insights

 Department-wise Attrition:
- Highest attrition in **R&D (56.12%)**
- Followed by **Sales (38.82%)** and **HR (5.06%)**

Age Distribution:
- Majority of employees are aged **25-44**
- High attrition in age group **25-34** (61.61%)

Job Satisfaction:
- **Research Scientists** and **Laboratory Technicians** show higher satisfaction (Levels 3 & 4)
- **Managers** and **Manufacturing Directors** have balanced satisfaction levels

Education Field:
- Highest attrition among employees from **Life Sciences**
- Followed by **Medical** and **Marketing** backgrounds
